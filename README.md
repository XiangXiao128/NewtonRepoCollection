# NewtonRepoCollection

Demo pages:

- [Isaac Demos](documents/demos_isaac.html): 9 videos.
- [Newton Demos](documents/demos_newton.html): 12 videos.

After downloading the repository, open an HTML page in `documents` with a browser to watch the videos. GitHub's repository view displays HTML source; the static pages can be published with GitHub Pages for online playback.

Each demo displays a video on the left and four information rows on the right: Description, Software Version, Source Repository, and Author. On narrow screens, the information appears below the video. To fill in the blank fields, edit the corresponding `<dd>` elements in the HTML file. Comments mark each field.
