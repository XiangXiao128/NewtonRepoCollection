## Name

## Description
Videos 01–06 showcase a tactile benchmark built on Newton. The benchmark evaluates both long-horizon and short-horizon tactile skills. Taking advantage of Newton’s ability to run multiple solvers in the same scene, we built the demos using **MujocoSolver and VBD**. The short-horizon skills include gentle grasping, blind-exploration grasping, curved-surface tool wiping, and hinged-object manipulation. The long-horizon task is to cut a banana and place the slices into a bowl retrieved through blind exploration.

## Software Version
Newton 1.6.1, Isaac Lab 3.0+, Isaac Sim 6.1
